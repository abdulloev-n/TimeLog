# TimeLog 1.0.5

First GitHub release, for Windows 10/11 x64.

- Local time entries, timer, projects, clients, and tags.
- Week and month reports, earnings by currency, and PDF invoices.
- Timer bar spans the window width with margins.
- Day entries show the newest interval first.
- Date and time fields enforce ranges and reject letters and clearing. Dates use years 1900–2100; entries last from one minute to 24 hours.
- Pomodoro shows a separate alert and repeats a sound until acknowledgment. Start break / Start work starts the next phase; Dismiss leaves it waiting.
- Pomodoro continues while the main window is hidden in the tray.

The source includes tests and build commands. Releases provides the Windows installer. User databases are excluded from both source and release files.
